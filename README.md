# Квант-7

Синтезатор и 16-шаговая ритм-машина в браузере. Чистые HTML/CSS/JS, без сборки и зависимостей, без cookie и трекеров.

## Структура

```
index.html          страница
assets/style.css    стили
assets/app.js       звук (Web Audio), секвенсор, коды паттернов, графика
assets/favicon.svg  иконка
tools/preview.sh    собирает версию для превью в Claude Artifacts (для хостинга не нужен)
```

## Запуск локально

Звук в браузере работает и с `file://`, но лучше через локальный сервер:

```sh
cd ~/Desktop/Quant-7
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как выложить в открытый доступ

Сайт статический, подойдёт любой бесплатный хостинг статики.

**GitHub Pages**
```sh
cd ~/Desktop/Quant-7
git init && git add . && git commit -m "Квант-7"
gh repo create quant-7 --public --source=. --push
gh api -X POST repos/{owner}/quant-7/pages -f "source[branch]=main" -f "source[path]=/"
```
Сайт появится на `https://<логин>.github.io/quant-7/`.

**Cloudflare Pages / Netlify**: перетащить папку в веб-интерфейс, поле build command оставить пустым.

Свой домен подключается в настройках любого из этих хостингов.

## Коды паттернов

Банк упакован в 36 байт: версия, темп, свинг, 9 ручек звука, 4×16 бит ритма, 16 шагов нот (нота, акцент, слайд). Дальше base32 с префиксом `Q7-`.
Ссылка вида `https://сайт/#Q7-XXXX…` при открытии загружает паттерн в текущий банк.

## Что дальше (идеи)

1. **Запись в WAV**: кнопка «Записать 4 такта» через `OfflineAudioContext`, файл скачивается.
2. **Кнопка «Ссылка на паттерн»**: копирует URL с кодом (`#Q7-…`), разбор уже готов.
3. **Цепочка банков**: A → B → A → C, то есть уже полноценный трек.
4. **Галерея паттернов**: небольшой бэкенд (Cloudflare Workers + KV), люди публикуют коды, остальные слушают в один клик.
5. **Web MIDI**: играть с настоящей MIDI-клавиатуры и синхронизироваться по MIDI clock.
6. **Второй модуль звука**: шумовой генератор / суб-осциллятор, LFO на срез.
7. **Гостевая книга** в духе старого интернета.
8. **PWA**: установка на телефон и работа офлайн (service worker).
